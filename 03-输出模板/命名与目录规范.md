# 命名与目录规范

## 根目录

`{公司}-{部门}-{姓名}-业务流梳理/`

示例：`示例制造-跟单部-张三-业务流梳理/`

## 根目录文件

| 文件 | 说明 |
|------|------|
| `00-企业与部门上下文摘要.md` | 行业 → 业务范围 → 部门 → 岗位 |
| `00-岗位业务清单（确认版）.md` | 事项列表与确认状态 |
| `00-填写人信息摘要.md` | 来自个人表 01 |
| `原始表-组织信息填写表-….xlsx` | 可选归档 |
| `原始表-个人工作事项填写表-….xlsx` | 建议归档 |
| `企业上下文卡.md` | 可选（无网/纠偏） |

## 业务流子目录

`flows/01-{事项短名}/`、`flows/02-{事项短名}/` …

- 序号与「岗位业务清单」一致  
- **短名**：去掉「的/进行」等虚词，保留动宾，≤20 字  
- **禁止**：空格与字符 `/ \ : * ? " < > |`  

## 确认状态

`草稿` → `待确认`（已出 Word）→ `已确认`（业务员确认通过）

未「已确认」前，`03`/`04`/`05` 不得标为定稿。
